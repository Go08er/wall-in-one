# Wall-in-One v0.3.2: All wallpapers, Pause and Store cache fixes

Pre-alpha bug-fix release on top of [0.3.1](v0.3.1.md). The companion is
unchanged: **Wall-in-One companion v0.2.1** for Noctalia 5.2 (plugin API 32)
is still the paired version, and Noctalia hosts at API 17–31 keep installing
companion v0.1.3. Wall-in-One runs on Wayland; X11 sessions are not supported.

All three fixes are for older bugs; none was introduced by 0.3.1.

## Fixes

- **A schedule rule or a display that plays All wallpapers is kept.** In the new window you can choose All wallpapers for a schedule rule or for a display's own playlist. The next start of the app took that choice for a playlist that no longer exists and removed it: the rule was deleted, and a display lost its playlist and its "beats the shared rules" setting. The wallpaper service always accepted these choices; the app now keeps them too.
  - If a schedule rule or a display's playlist of yours disappeared after a restart, set it again.
- **A crashed wallpaper renderer no longer cancels Pause.** If the video renderer exited while playback was paused, the wallpaper service switched back to playing and could move on to the next wallpaper without a Play. Pause and Stop now hold, in both display modes, also when a schedule moves a paused display on. The failure is still reported, and Play (or Play/Pause) starts the renderer again.
- **Browsing the Store keeps the thumbnail cache within its size limit.** Store previews were saved without the cache's cleanup, so a long browse could grow `~/.cache/wall-in-one/thumbnails` past its 256 MiB limit. Saving previews now runs that cleanup too, at most once every 30 seconds so browsing stays light.

## Updating

**From 0.3.0 or 0.3.1:** update the app and refresh its service definitions as usual. The wallpaper service changed in this release, so restart it. There is no companion update.

**From 0.2.x or 0.1.4:** read the [0.3.0 release notes](v0.3.0.md) first. Updates are one-way: going back to an older version afterwards is not supported.

## Test scope

Every check in the flake passed on the release commit: 1,626 GUI tests on a private headless Wayland compositor, the unit, golden-profile and upgrade suites, the wallpaper service's own tests, and the desktop and update VMs. Each fix has a test that fails on 0.3.1.
